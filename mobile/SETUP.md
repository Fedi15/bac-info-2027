# Mobile setup

This is intentionally a Flutter source project plus native bridge templates. The build environment used to prepare this archive does not contain Flutter or Xcode, so it cannot honestly ship a compiled Android/iOS platform tree generated by those SDKs.

## 1. Generate the standard platform shells

On Windows/Linux:

```powershell
cd mobile
./setup.ps1
flutter pub get
```

Or manually:

```text
flutter create --platforms=android,ios --org com.torbaga --project-name torbaga_prof .
flutter pub get
```

## 2. Android

Replace the generated `android/app/src/main/kotlin/com/torbaga/torbaga_prof/MainActivity.kt` (or the package path generated by Flutter) with `native_templates/android/MainActivity.kt` and update its package declaration if your generated package differs.

Add the provider/query entries from `native_templates/android/AndroidManifest.additions.xml` to the generated manifest and copy `native_templates/android/file_paths.xml` to `android/app/src/main/res/xml/file_paths.xml`.

The Android bridge uses Instagram's `com.instagram.share.ADD_TO_STORY` handler and a FileProvider URI, so there is no generic Android share chooser for the Instagram button.

## 3. iOS

Replace the generated `ios/Runner/AppDelegate.swift` with `native_templates/ios/AppDelegate.swift` while preserving the generated Flutter files and `GeneratedPluginRegistrant`.

Add `instagram-stories` to the generated `LSApplicationQueriesSchemes` array as shown in `native_templates/ios/Info.plist.additions.xml`.

The iOS bridge puts the JPEG in the Instagram pasteboard key `com.instagram.sharedSticker.backgroundImage` and opens `instagram-stories://share`.

## 4. Run

Android:

```text
flutter run
```

iOS:

```text
flutter run -d <your iPhone>
```

iOS compilation/signing requires macOS + Xcode.
